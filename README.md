# Pondicherry IT & Software Companies Field Tracker & Verification CRM

A modern, high-performance, mobile-responsive React web application tailored for job hunting and business outreach across verified IT & software companies in Pondicherry.

## 🌟 Key Features
- **Field & Call Tracking:**
  - **Calling Status:** *Not Called*, *Called - Follow Up Needed*, *Called - Positive / Interview Scheduled*, *Called - Not Hiring / Rejected*, *No Answer / Switched Off*.
  - **Physical Visit Status:** *Yet to Visit*, *Direct Visit Completed - Met HR/Manager*, *Office Found & Verified*, *Office Shifted / Not at this Address*.
  - **Contact & Notes:** Dedicated editable contact person (HR name/role) and field notes per company.
- **Quick Action Triggers:**
  - 📞 **Call Now:** Direct `tel:` link opens phone dialer instantly.
  - 🗺️ **Navigate:** Direct Google Maps turn-by-turn routing with verified Pondicherry landmarks.
  - 🌐 **Website & Email:** One-tap official site visit and email dispatch.
- **Live Metrics Dashboard:**
  - Real-time progress bar for calls made vs remaining balance.
  - On-ground physical visits completed vs balance to visit.
  - Positive leads and interviews identified counter with celebratory confetti!
- **Views & Filtering:**
  - **Grid Card View:** Touch-optimized for smartphones when traveling on bike/car.
  - **Spreadsheet Table View:** Desktop-optimized for high-speed mass calling and notes review.
  - **Area & Status Filters:** Filter by White Town, Heritage Town, Lawspet, Pakkumudayanpet, Mudaliarpet, Murungapakkam, Ellaipillaichavady, Thattanchavady, Villianur, Saram, Muthialpet, etc.
  - **Real-time Search:** Instant keyword search across company name, tech stack, and address.
- **Data Management:**
  - Auto-saved into browser `localStorage`.
  - Export into **Excel (.xlsx)**, **CSV (.csv)**, or **JSON**.
  - "Add Company" modal to add new tech enterprises on the go.
  - "Reset to Factory Data" option.

## 🚀 Running Locally
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
